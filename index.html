About

Clean code, secure access, systems that last

I'm a .NET developer from Lahore, Pakistan, with five years of building and maintaining production web applications. Today I'm a Senior Software Engineer at NODLAYS, focused on authentication, access control, API design and maintainable service architecture.

Much of my work sits where business rules meet security: Azure AD B2C sign-in with role-based permissions enforced in both the API and the Angular app, Stripe subscriptions and webhooks, SignalR real-time features, and new Clean Architecture systems that still work with a legacy database.

I'm known for strong debugging, working well with QA and product teams, and leaving code cleaner than I found it. Outside client work I build open-source tools, most recently an SEO auditing skill for AI coding agents.
